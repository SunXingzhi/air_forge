## 1. 产品定位与原始需求基线

### 1.1 使用场景

桌面焊接工位（手工烙铁焊 / 少量返修）旁的近场吸气净化设备：万向臂末端集气罩就近捕集焊烟，经三级滤芯净化后由离心风机排出，实时把「处理前 / 处理后」的气体数据呈现在机身屏幕上。

### 1.2 污染物与工艺链（基线，不变）

废气中同时存在两类形态不同的污染物，去除机理不同，因此必须分级处理：

| 污染物 | 形态 | 主要来源 |
|---|---|---|
| 铅 | 固态颗粒 | 含铅焊料 / 母材受热蒸发 |
| 锡 | 固态颗粒 | 焊锡 / 镀锡件受热 |
| 甲醛 | 气态 | 助焊剂热分解 |
| 苯系物 | 气态 | 助焊剂 / 清洗剂 |

固定工艺路线（**先颗粒、后气态；先过滤、后风机**）：

```
集气罩 → ① 不锈钢金属网（粗滤）→ ② 玻纤/PTFE 覆膜中效滤棉
      → ③A 浸渍活性炭（甲醛）→ ③B 颗粒活性炭（苯系物）
      → ④ 离心风机（末端，箱体负压）→ 排放
```

### 1.3 设计与验收约束（基线，不变）

| 约束 | 数值 / 要求 | 来源 |
|---|---|---|
| 进入活性炭层的颗粒物浓度 | ≤ 1 mg/m³（超过必须先预过滤） | GB 51401-2019、HJ 2026-2013 |
| 进入吸附层的废气温度 | < 40 ℃ | HJ 2026-2013 |
| 滤料选型 | 含磨琢性金属粉尘，优先玻纤 / PTFE 覆膜；前端金属网粗拦截 | HJ 2020-2012、HJ 1292-2023 |
| 维护方式 | 滤芯模块化、可抽拉更换；一级金属网可水洗复用 | 结构方案 |

### 1.4 结构与交互基线（结构方案原始设想）

- 结构：离心风扇 + 进气孔/排气孔 + 万向臂 + N 层可抽拉滤网；顶部仿黑胶唱片式旋转换芯结构；可考虑开透明观察孔看滤网状态。
- 原交互方案：可视化屏幕（显示处理前后气体成分与效果量化数据）+ **电源键** + **吸力切换键（停-弱-中-强-停）** + 「查看滤网寿命」键 + 「情绪按键（灯光/音乐）」+ 「返回上一级」键 + **旋转编码器**。

> 原始方案共有 1 个电源键 + 4 个功能键 + 1 个编码器 + 1 块屏幕，按键与编码器承担了绝大部分导航职责。

## 2. 本次需求变更

| 编号 | 变更内容 | 变更前 | 变更后 |
|---|---|---|---|
| CR-01 | 人机交互载体 | 按键 + 编码器导航，屏幕仅作显示 | **绝大多数人机交互通过 1.69″ LCD 电容触摸屏完成**；屏幕同时是唯一的信息出口与主要输入通道 |
| CR-02 | UI 软件方案 | 未定 | **采用 LVGL v9 作为 UI 框架与逻辑层**，并用自定义动画路径复刻 OLED_UI 的平滑曲线光标/滚动质感；OLED_UI 仅作动效与视觉参考，不作为运行时代码（详见第 4 章） |
| CR-03 | 物理控件精简 | 电源键、吸力键、滤网键、情绪键、返回键、编码器 | **仅保留：1 个电源键、1 个功能切换键、1 个电源灯、1 个状态灯** |
| CR-04 | 派生删除项 | 情绪按键（灯光/音乐）、旋转编码器、独立返回键、独立滤网键 | 全部取消，改为触摸屏内的页面/手势；情绪灯光外设不在本期范围 |

### 2.1 变更带来的直接影响

1. 「风量切换」由触摸屏内的档位控件承担，物理功能键保留为**全局快捷键**（不进入任何页面也可操作）。
2. 「返回上一级」「查看滤网寿命」「情绪」等入口全部合并进触摸页面树，页面层级需控制在 **≤ 2 级**，避免小屏深层导航。
3. 触摸屏成为唯一信息出口，因此必须定义：状态栏常驻信息、告警弹窗规则、息屏/唤醒规则、故障时的降级显示。
4. 物理控件减少后，**设备在触摸失效（触摸 IC 异常、屏幕排线松动）时仍需可安全运行**：功能键可切风量、电源键可关机、状态灯可报故障。

## 3. 人机交互需求

### 3.1 物理控件定义（仅 4 个）

| 编号 | 控件 | 类型 | 行为定义 | 优先级 |
|---|---|---|---|---|
| R-UI-01 | 电源键 | 轻触按键（带硬件自锁或软自锁电路） | 短按：屏幕息屏 ↔ 唤醒；长按 3 s：软关机（关风机 → 关屏 → 断电保持）；长按 10 s：硬件强制断电 | P0 |
| R-UI-02 | 功能切换键 | 轻触按键 | 短按：风量循环 **停 → 弱 → 中 → 强 → 停**（任意页面均生效，并弹出 2 s 档位提示窗）；长按 3 s：直达「滤芯寿命」页面（维护快捷入口） | P0 |
| R-UI-03 | 电源灯 | 单色 LED（建议绿色） | 常亮 = 整机上电且主控运行；熄灭 = 关机/断电。仅反映**电源状态**，不参与告警 | P0 |
| R-UI-04 | 状态灯 | 单色或双色 LED（建议蓝/琥珀/红三态或单色闪烁编码） | 见 3.4 状态灯语义表 | P0 |

> 按键需满足：≥ 10 万次寿命、行程明确、可盲操作（戴手套可感知段落感）；两个按键的物理位置需在结构上可区分（电源键带凹陷/独立颜色）。

### 3.2 触摸交互手势（唯一定义，不得扩展）

| 手势 | 语义 | 适用范围 |
|---|---|---|
| 单击 | 选中 / 进入 / 执行 | 全域 |
| 上滑 / 下滑 | 列表滚动、数值加减 | 列表页、数值调节项 |
| 左滑（自右向左） | 返回上一级 | 非主页面 |
| 双击 | 风量档位快速循环（与功能键短按等效） | 主页面 |
| 长按 1.5 s | 进入「设置」 | 主页面空白区 |

交互硬性规则：

- 可点击区域 ≥ 44 × 44 px（240 × 280 屏上约 1/6 宽），相邻可点击元素间距 ≥ 8 px。
- 防误触：同一次触摸只产生一个语义事件；滑动过程不触发点击。
- 触摸响应反馈 ≤ 100 ms（视觉高亮 / 光标反色）。
- 屏幕无操作 60 s 自动息屏（可设置 30 s / 60 s / 常亮），息屏后任意触摸或按键唤醒，**唤醒动作本身不触发业务操作**。

### 3.3 页面结构（≤ 2 级）

```
P0 启动页（Logo + 传感器自检进度，≤ 3 s，可跳过）
└─ P1 主页面（仪表盘 / 图标入口，常驻状态栏）
   ├─ P2 风量控制        （列表：停 / 弱 / 中 / 强 / 自动）
   ├─ P3 滤芯寿命        （列表：一级 / 二级 / 三级A / 三级B + 复位）
   ├─ P4 实时数据        （处理前 / 处理后对比 + 净化效率 + 趋势）
   └─ P5 设置            （亮度 / 息屏 / 单位 / 校准 / 关于）
弹窗层 W：档位提示、换芯提醒、传感器异常、过热保护、恢复出厂确认、关机确认
```

### 3.4 页面信息架构

**P1 主页面**

| 区域 | 内容 | 说明 |
|---|---|---|
| 状态栏（顶部，常驻） | 风量档位图标、滤芯剩余寿命 %、告警图标、Wi-Fi 状态（预留） | 高度约 32 px，任何页面均显示 |
| 数据区（主体） | 「处理前 / 处理后」两组 PM2.5 与 TVOC 数值 + 净化效率 % 大字 | 这是原始需求中"处理前后气体成分与处理效果量化数据"的落点 |
| 入口区 | 2 × 2 图标块：风量、滤芯、数据、设置 | 对应 4.4 的 LVGL 图标块布局 |
| 底部 | 当前运行时长 / 累计运行时长 | 支撑滤网寿命估算 |

**P2 风量控制**：档位单选（停/弱/中/强/自动）、当前档位反色光标、切换即时生效并有 2 s 提示窗。

**P3 滤芯寿命**：四条寿命条（金属网 / 中效滤棉 / 活性炭A / 活性炭B）、剩余天数与百分比、到期项高亮、「已更换」复位项（需长按确认）。

**P4 实时数据**：处理前后 PM2.5、TVOC 数值与比值；近 60 s 迷你趋势；传感器状态（正常/预热中/异常）。

**P5 设置**：屏幕亮度（3 档）、息屏时间、单位切换（μg/m³ / ppm）、传感器零点校准（需长按 + 确认）、恢复出厂、版本与序列号。

### 3.5 状态机

```
        上电
         │
     ┌───▼────┐  自检失败   ┌─────────┐
     │ 自检    ├───────────►│ 故障态   │
     └───┬────┘             └────┬────┘
         │ 自检通过               │ 故障消除/复位
     ┌───▼────┐◄─────────────────┘
     │ 待机    │  （风量=停，屏幕可息屏，状态灯呼吸）
     └───┬────┘
         │ 风量 > 停 / 触摸操作
     ┌───▼────┐
     │ 运行    │  风量 弱/中/强/自动
     └───┬────┘
         │ 长按电源键 3 s
     ┌───▼────┐
     │ 关机    │  风机停 → 屏灭 → 断电保持
     └────────┘
```

故障态优先级：过热保护 > 传感器异常 > 通信异常 > 滤芯到期提醒（提醒不进入故障态）。

### 3.6 状态灯语义（R-UI-04 细化）

| 设备状态 | 状态灯表现（三色方案） | 单色方案（闪烁编码） |
|---|---|---|
| 运行中 | 蓝色常亮 | 常亮 |
| 待机 / 息屏 | 蓝色呼吸（1.5 s 周期） | 慢闪 1 Hz |
| 滤芯即将到期（≤ 15%） | 琥珀色常亮 | 双闪 2 次 / 2 s |
| 滤芯到期 | 琥珀色快闪 | 快闪 4 Hz |
| 故障 / 过热保护 | 红色常亮或快闪 | 快闪 4 Hz + 电源灯保持常亮以区分断电 |

规则：状态灯**不得**与电源灯合并为同一颗；任何灯效不得作为唯一告警手段，必须同时在屏幕（可用时）给出文字说明。

### 3.7 告警与提醒规则

| 事件 | 触发条件 | 呈现 | 可抑制 |
|---|---|---|---|
| 换芯提醒 | 任一滤芯寿命 ≤ 15% / = 0 | 弹窗 + 状态灯琥珀；到期后每 24 h 再提醒一次 | 24 h 内可「稍后提醒」 |
| 传感器预热 | 上电后 MOX 类传感器未稳定 | 数据区显示「预热中」占位，不显示数值 | 不可抑制 |
| 传感器异常 | 读数超量程 / 断线 / 长时间无变化 | 弹窗 + 状态灯红；该通道数据置灰 | 不可抑制 |
| 过热保护 | 排气或箱内温度 > 45 ℃ | 自动降档 → 停风机 + 红闪 + 弹窗 | 不可抑制 |
| 触摸失效降级 | 触摸连续 30 s 无响应（自检心跳） | 状态灯红慢闪；屏幕提示「触摸异常，请使用功能键」 | 不可抑制 |

## 4. UI 软件方案：LVGL v9 基线 + 复刻 OLED_UI 动效

### 4.1 选型结论

基线由 OLED_UI 改为 **LVGL v9**；OLED_UI **不再作为运行时代码**，仅作为动效与视觉的参考样本。理由：

1. LVGL 原生 RGB565 彩色 + 脏矩形局部刷新 + DMA，**不需要写 1bpp → RGB565 适配层**。
2. 原生 `indev` 触摸抽象，**不需要把触摸映射成虚拟四键**。
3. 适配层由 Espressif 侧维护，版本活跃，规避 OLED_UI 在 ESP32 上的已知指针 bug 与维护空窗。
4. 动效能力覆盖并超过 OLED_UI：内置 ease/overshoot 路径 + 自定义 `path_cb`，可复刻甚至更细腻地实现「像素平滑曲线」。

| 维度 | OLED_UI（原方案） | LVGL v9（本方案） |
|---|---|---|
| 显示模型 | 单色 1bpp，整帧刷新 | RGB565 / ARGB8888，脏矩形局部刷新 |
| 触摸 | 无触摸模型，需虚拟四键映射 | 原生 indev，`esp_lcd_touch` 直连 |
| 控件 | 仅菜单 / 窗口 / 图标块 | list / bar / chart / tabview / switch / slider / table |
| 动效 | 内置 UNLINEAR、PID_CURVE 光标 | 内置 ease/overshoot + 自定义 `path_cb` |
| 字体 | 8/12/16/20 点阵，UTF-8 需改宏 | 点阵 / 矢量均可，中文需子集裁剪 |
| 资源 | 极小 | 较大（16 MB Flash + 8 MB PSRAM 足够） |
| 维护 | 个人项目，ESP32 指针 bug 待重构 | Espressif 官方适配，版本活跃 |

### 4.2 技术基线（版本需实测后锁定）

| 项 | 基线 | 说明 / 风险 |
|---|---|---|
| UI 框架 | LVGL **v9.x** | 网上教程多为 v8，`lv_obj`/事件/动画 API 有差异，照抄会踩坑 |
| 适配层 | `espressif/esp_lvgl_port`（首选）或 `espressif/esp_lvgl_adapter` | esp_lvgl_port 声明 IDF ≥4.4 / LVGL 8~9；esp_lvgl_adapter 声明 IDF ≥5.5 / LVGL 8~9；本项目 **IDF 6.1.0 无显式声明**，必须 build 实测后锁版本 |
| 显示驱动 | ESP-IDF `esp_lcd` 的 ST7789 panel + SPI + DMA | 240×280 是在 240×320 显存内开窗，**y 偏移需实测**（0 或 20 起，写错会整屏错位） |
| 触摸驱动 | `espressif/esp_lcd_touch_cst816s` | 该组件目标为 **CST816S**，本屏为 **CST816T**，需核对芯片 ID/寄存器；不一致时退回裸 I2C 驱动 |
| 资源 | 16 MB Flash / 8 MB Octal PSRAM | 中文字库必须子集化，全量 CJK 不可行 |

### 4.5 平滑曲线的手感实现（关键项，需在样机上标定）

「像素平滑曲线」不是 LVGL 的现成开关，由两部分合成：

1. **路径**：光标 y 用 `lv_anim` 驱动，`lv_anim_set_path_cb(&a, spring_path)`。`spring_path` 返回临界阻尼弹簧解（ζ = 0.7~1.0）：
   `x(t) = target + (start - target) · e^(-ζωt) · (1 + ωt)`
   允许返回值超过 1024 以获得轻微过冲；也可先用内置 `lv_anim_path_overshoot` 起步再微调。
2. **像素感**：点阵字体 + 关闭抗锯齿 + 整数坐标 + 1 px 描边 + 黑底单色，避免矢量渐变破坏「点阵屏幕」的观感。
3. **标定项**：`MovingSpeed 4` ↔ 180–260 ms；`PID_CURVE` ↔ ζ≈0.7 的弹簧（轻微回弹）；列表滚动的 `scroll_elastic` 调小以复刻逐项吸附。

> 验收同时看主观手感与客观指标：与 OLED_UI 示例逐帧对比动画节奏，并满足 4.6 的帧率/延迟门槛。

### 4.6 资源与性能预算

| 项 | 预算 | 说明 |
|---|---|---|
| 帧缓冲 | 13.4 KB × 2（1/10 屏）或 134.4 KB × 2（整屏，PSRAM） | `LV_COLOR_DEPTH = 16` |
| LVGL heap | 64–128 KB（PSRAM） | 控件规模小，够用 |
| 字体 | 界面文案冻结后生成中文子集 | 全量 CJK 放不进 Flash |
| 帧率 | ≥ 25 fps（目标 30–40） | 局部刷新 + DMA |
| 触摸 → 高亮 | < 100 ms | 与 3.2 一致 |

## 7. 风险与待确认问题

| 编号 | 风险 / 问题 | 影响 | 建议动作 |
|---|---|---|---|
| Q-01 | LVGL 适配层（esp_lvgl_port / esp_lvgl_adapter）未声明支持 ESP-IDF 6.1.0 | 依赖不满足、编译失败或运行异常 | 先做最小工程 build 验证，锁定组件版本并记录到 manifest / lock |
| Q-02 | 触摸组件 `esp_lcd_touch_cst816s` 面向 CST816S，本屏为 CST816T | 读不到坐标或数据异常 | 核对芯片 ID 与寄存器；不一致时自写裸 I2C 驱动 |
| Q-03 | 触摸替代物理键后，触摸失效即失去主要输入 | 可用性风险 | 已定义降级路径（R-UI-01/02 + 状态灯），需在验收中实测 |
| Q-04 | 传感器数量与原方案不符（原设想 TVOC/甲醛/苯/金属氧化物四路，实购仅 MS1100 + GP2Y1014AU） | 「分项显示」需求无法完全满足 | 确认是否降级为「气态综合 + 颗粒物」两通道；若必须分项，需补传感器 |
| Q-05 | 无压差/温度传感器 | 滤芯寿命只能估算；无法验证 < 40 ℃ 约束 | 本期按时长估算 + 温度列为 H-04，寿命精度在文档中标注为「估算值」 |
| Q-06 | 24 V→5 V 降压、FPC 座、电源自锁未采购 | 无法上电联调 | 优先补 H-01 / H-05 / H-06 |
| Q-07 | 原方案「情绪按键 / 灯光 / 音乐」被取消 | 产品卖点减少 | 由需求方确认是否接受（本文件按取消处理） |
| Q-08 | 中文点阵字库子集化 | 字库过大挤占 Flash，或漏字导致界面缺字 | 界面文案冻结后生成子集，纳入构建流程并做缺字检查 |
| Q-09 | ST7789 在 240×320 显存中的开窗偏移 | 画面整体错位或裁切 | 实测定 y 偏移，写入初始化序列并固化到配置 |
