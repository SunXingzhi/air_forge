## 五、已知限制与后续事项

1. **`third_party/` 不入库**：LVGL 与 SDL2 需通过 `python scripts/fetch_deps.py` 恢复；CI 已自动化这一步。
2. **`sdkconfig` 不入库**：固件构建配置未提交，后续建议补充 `sdkconfig.defaults`（target esp32s3、PSRAM 等）。
3. **固件尚未接入 LVGL**：`app_main` 仍走厂商 demo；接入 `flush_cb` + `indev` 后可直接复用 `ui/`。
4. **像素字体仅 ASCII**：界面为英文；中文显示需生成 CJK 像素字库（如 Zpix / 缝合像素字体）。
5. **许可证选择**：当前为 MIT，如需 Apache-2.0 / GPL 等其他协议，可在 `LICENSE` 中替换并在 README 同步更新。

## 六、复现发布环境的命令

```powershell
# Windows 仿真
python scripts/fetch_deps.py
cmake -S sim -B sim/build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Debug
cmake --build sim/build -j 8
.\sim\build\air_forge_sim.exe
```

```bash
# Linux 仿真
sudo apt install build-essential cmake pkg-config libsdl2-dev
python3 scripts/fetch_deps.py --lvgl-only
cmake -S sim -B sim/build -DCMAKE_BUILD_TYPE=Debug
cmake --build sim/build -j
./sim/build/air_forge_sim
```
